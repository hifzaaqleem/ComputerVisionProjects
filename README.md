# 👁️ Computer Vision Projects

Welcome to my **Computer Vision Projects** repository! This collection features various real-time AI and computer vision applications built using Python, OpenCV, MediaPipe, and deep learning frameworks.

---

## 📂 Projects Directory

| Project Name | Description | Tech Stack |
| :--- | :--- | :--- |
| **😊 Face_Exp_Detect** | Real-time facial expression and emotion detection using webcam feeds and deep learning. | Python, OpenCV, TensorFlow/Keras |
| **🚶‍♂️ in-store-human-detection** | Automated human detection and tracking system tailored for retail/in-store environments. | Python, OpenCV, YOLO / Object Detection |
| **✊ Rock, Paper, Scissors** | Interactive hand-gesture game where you play against an AI opponent using your webcam. | Python, OpenCV, MediaPipe |

---

## 🛠️ General Tech Stack
The projects in this repository leverage standard computer vision and machine learning libraries:
- **Language:** Python 3.x
- **Image Processing:** OpenCV (`opencv-python`)
- **Mathematical Computations:** NumPy
- **AI & Feature Extraction:** MediaPipe, TensorFlow / Keras, Ultralytics YOLO
