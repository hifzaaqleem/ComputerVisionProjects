An end-to-end Computer Vision application engineered to detect people and objects in retail store environments. Powered by a fine-tuned **YOLOv8** model and featuring an interactive web interface built with **Gradio**.

---

## 🌟 Key Features

* **High-Precision Detection:** Fine-tuned object detection tailored for store and retail footage analytics.
* **Interactive Threshold Tuning:** Adjust model confidence dynamically via the Gradio interface slider.
* **Streamlined Inference Pipeline:** Handles image transformations and rendering directly in Python.
* **Hugging Face / Web Ready:** Formatted for easy deployment on Hugging Face Spaces or custom web servers.

---

## 🏗️ Tech Stack

* **Deep Learning Framework:** PyTorch & Ultralytics YOLOv8
* **Image Processing:** OpenCV, Pillow, NumPy
* **User Interface:** Gradio
